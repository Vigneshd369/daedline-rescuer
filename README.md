# Deadline Rescuer

A deadline planner that tells you how many hours to work today so nothing slips.

## Run in VS Code
1. Unzip and open the `deadline-rescuer` folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension, right-click `index.html`, choose "Open with Live Server".
   (Or just double-click `index.html`; no build step, no dependencies.)

## Features
- Live countdown to your next deadline
- Urgency ranking (time left vs. work remaining)
- Daily rescue plan compared against your own study capacity
- Progress sliders, mark done, delete, sample data
- Saved in your browser (localStorage)

Files: `index.html`, `style.css`, `script.js`
